Files in this directory are configuration and input data for the pipeline.

- `gsn_to_abbrev.json` — maps GSN (Gesetzesnummer) to the official or synthetic abbreviation
- `final_gsn_list.json` — the list of laws the pipeline processes; generated by the index → scan → match → disambiguate workflow
- `law_catalog_merged.json` — merged law catalog fetched from the OGD API; provides full law names
- `synthetic_abbrevs.json` — plausible abbreviations for laws that have no official Kurztitel
- `laws_index.json` — pre-built index used by the BFF (`bff/server.py`) to serve the law list quickly

All data originates from the Austrian OGD API v2.6:
https://data.bka.gv.at/ris/api/v2.6/Bundesrecht
